# Mysterium 0.10 公开测试版

正式版仍位于网站根目录；本测试版独立位于 `beta/`。测试版不会替换正式版的应用、样式或图片。

- [打开测试版](https://old-paper.github.io/mysterium-tarot/beta/)
- [返回正式版](https://old-paper.github.io/mysterium-tarot/)
- [图版与方法来源](SOURCES.md)

测试版包含完整阅读工作台、洗切与盲选、观察与复盘、42 → 35 张真实余牌续读、三套独立牌面与逐牌来源、分段 AI 提示词预览。没有外部 AI 请求、账号、跟踪器或自动上传。

## 与正式版隔离

正式版唯一页面改动是右下角“体验测试版”链接及其独立样式；点击在新标签页打开，不重抽或修改正式版当前阅读。

本机记录使用 `mysterium.beta.local-readings.v2`，显示偏好使用 `mysterium.beta.density`。不读取、迁移、覆盖或删除正式版的记录键。阅读内容只有主动保存才持久化；导入 / 导出仅由用户主动执行。浏览器本机存储仍按域名共享底层空间，键名隔离不是安全沙箱；不要导入不信任的文件。

## 后续更新

仅更新 `beta/` 中经过验收的运行文件和素材，保留测试版标题、正式版入口及独立存储键。不要将开发目录中的 `.git`、本机备份、测试截图、下载日志或研究输入放入公开目录。

基础版本通过 136 项本地算法与浏览器检查。发布前另检查正式版保留、子路径资源、测试标识、存储隔离及双向入口；这些验证不代表预测准确率。中文对照是本站译稿，不是完整学术定本。

若以后希望把测试版提升为正式版，应另行确认；不得通过更新测试版顺带覆盖网站根目录。
